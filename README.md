# По неделям

Личный трекер бюджета: Cloudflare Workers + D1, локальный режим на Python 3.11+ и SQLite.

## Финансовая модель

Суммы хранятся в целых копейках. Недели идут с понедельника по воскресенье и обрезаются границами месяца. Бюджет распределяется пропорционально числу дней без потери копеек.

Закрывать недели можно только по порядку. При закрытии экономия или перерасход учитываются в следующей неделе либо распределяются на оставшиеся. Исторический лимит сохраняется, сумма расчёта хранится в `settled`.

Кнопка «Открыть неделю для исправлений» открывает выбранную и последующие недели. Расходы сохраняются; лимиты открытых недель распределяются заново. После этого можно удалить неверную трату и добавить правильную. Закрытые недели до выбранной сохраняются.

Из полностью закрытого месяца можно переносить остаток в следующий. Перенесённые деньги вычитаются из доступного бюджета источника. Повторное открытие источника не отменяет перенос: увеличить расходы или уменьшить бюджет так, чтобы затронуть уже перенесённые средства, нельзя. После повторного закрытия можно перенести оставшуюся доступную сумму.

Изменение бюджета полностью закрытого месяца корректирует остаточный лимит последней недели. При недостатке средств для уже учтённых предыдущих недель изменение отклоняется.

Файлового импорта и экспорта нет. Данные сохраняются на сервере. Интерфейс получает актуальное состояние при входе и после каждой операции. Конфликт ревизий обновляет локальное состояние и требует повторить изменение.

Каждая операция имеет уникальный ID. Сервер атомарно сохраняет изменение и квитанцию операции; повтор запроса не создаёт второй расход. После потери ответа клиент автоматически повторяет запрос с тем же ID. Если результат всё ещё неизвестен, клиент обновляет состояние по возможности и просит проверить список трат.

## Структура

- `web/` — интерфейс; `api-client.js` отвечает за безопасный повтор операций.
- `cloudflare/budget.mjs`, `budget.py` — облачная и локальная финансовая логика. Их совместимость проверяется тестами.
- `cloudflare/worker.mjs`, `server.py` — API, авторизация, атомарное сохранение и квитанции.
- `cloudflare/migrations/` — миграции D1, включая таблицу `operations`.
- `tests/` — расчёты, API, совместимость, повтор запросов, браузер и локальный Worker.

## Локальный запуск

```powershell
python server.py
```

Открыть http://127.0.0.1:8000. Данные аккаунтов хранятся в `data/finance.sqlite3`, вне Git. Локальный HTTPServer предназначен для разработки; регистрация свободная.

## Проверки

```powershell
npm ci
npm test
npm run test:client
npm run test:parity
npm run format:check
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD/data/browsers"
npx playwright install chromium
npm run test:browser
```

Браузерные тесты используют отдельную БД и проверяют исправления, удаление из истории, потерю ответа после сохранения, перезагрузку и размеры 320/360/390 px. Реальные iOS/Android требуют отдельной проверки.
