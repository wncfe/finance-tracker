# По неделям — перенос на Cloudflare

1. Открой эту папку в локальном Codex/Claude Code или другом агенте.
2. Попроси: «Прочитай AGENT_TASK.md и выполни перенос проекта на Cloudflare».
3. Войди в свой Cloudflare при запросе авторизации.
4. Дай агенту проверить работу и получить конечную ссылку.

## Что внутри

- `stable-frontend/` — исходники опубликованной и проверенной версии: интерфейс, недельные расчёты, локальное хранение и JSON-резервные копии. Можно открыть index.html локально. Прямая запись в файл зависит от браузера и безопасного контекста.
- `sync-draft/` — НЕЗАВЕРШЁННАЯ, НЕ ОПУБЛИКОВАННАЯ доработка: интерфейс синхронизации, черновик API, валидация и SQL-схема. Это справочный исходник для агента, не готовый деплой. API route.ts пока использует специфичные импорты ChatGPT Sites.
- `AGENT_TASK.md` — задание локальному агенту.

В архиве нет расходов пользователя, токенов, ключей, node_modules и служебной конфигурации ChatGPT Sites. Данные браузера автоматически в исходники не попадают.

## Существующие записи

Если ты уже вносил расходы, перед переносом скачай JSON-копию с исходного сайта:
https://lesha-weekly-budget.recentnook.chatgpt.site

После готовности нового сайта импортируй этот JSON через интерфейс и дождись статуса сохранения на сервере. У нового адреса отдельное хранилище браузера.

Существующий сайт ChatGPT продолжает работать в прежней версии: новая серверная версия там не публиковалась.
