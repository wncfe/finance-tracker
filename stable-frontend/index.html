Сохранение

Твой файл на ПК

Подключи файл один раз — изменения будут записываться в него автоматически, пока страница открыта.

Если очистить данные браузера

Файл на диске останется. Нажми «Открыть файл бюджета» и выбери его снова. В нём хранятся все твои месяцы. Файл нужно сохранить хотя бы один раз до очистки.

Прямая запись доступна в совместимых браузерах на ПК, например Chrome и Edge. Если её нет, скачивай резервную копию после изменений и загружай её при следующем открытии.

Без подключения файла данные сохраняются только в этом браузере. Расходы никуда не отправляются.
